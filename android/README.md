# MB Android

安卓客户端在 `android` 分支独立开发，参考 iOS 0.1.0 Build 23（`8c6522c`）。0.1.11 预览 APK 沿用 0.1.10 的签名，可覆盖安装，不需要先卸载。已实现、已实测和待补项见 [PARITY.md](PARITY.md)。桌面与 iOS 公开发行包不是安卓版本。

## 终端构建

需要 JDK 17、Android SDK Platform 36.1、Build-Tools 36.1.0、NDK `28.2.13676358` 和 CMake `3.22.1`。应用最低支持 Android 8.0（API 26）。

```sh
export ANDROID_HOME="$HOME/Library/Android/sdk"
export JAVA_HOME=$(/usr/libexec/java_home -v 17)
cd android
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Debug APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。以上命令不会启动 IDE 或模拟器。显式执行设备测试时，只用独立的无窗口模拟器或用户指定的设备；不复用手机端生产账号。

原生音频与 QuickJS 宿主测试需另构建 `:app:assembleDebugAndroidTest`。把两个 APK 安装到专用的干净测试设备或模拟器用户后，用 `adb -s <测试设备序列号> shell am instrument -w com.xtreeroot.mb.test/androidx.test.runner.AndroidJUnitRunner` 运行。播放回归需要初始队列为空。测试使用生成的 PCM 波形和固定插件响应，不要求联网或账号。

## 卸载后保留资料库

导入和下载的歌曲都能从本地资料库播放；缓存不算入库。播放页的 **本地喜欢** 独立于平台点赞。移除或停用音源插件不影响已下载音频。

点专辑或歌手可进入分组详情。分组和歌单里的 **播放全部**、**随机播放** 只会加入当前搜索命中的歌曲。同名专辑优先按专辑作者区分；没有专辑作者时，文件夹导入用目录摘要区分，单独选文件用曲目作者区分。备份不记录导入目录路径。

导入文件夹时，同目录的有效同名 `.lrc` 优先于内嵌歌词；无有效 LRC 时读取 MP3 或 M4A/MP4 的内嵌歌词。单独选音频时，Android 只授予该文件的访问权限，不能扫描同目录的 LRC；可以在曲目菜单手动附加。

在 **资料库 → 数据位置** 中选择一个独立于 App 的本机文件夹，例如 `Documents/MB`。MB 在所选文件夹下创建 `MB Data`，页面显示选中的文件夹名和最近备份时间。增量备份包含已导入和下载的音频、歌单、喜欢、最近播放记录、本地歌词、搜索历史、播放队列、自定义背景、非敏感设置和已安装的插件包。插件只备份安装文件和预设选项，不备份启用状态、密码、自由输入配置或 `host.storage`。APK、工作数据库、在线播放缓存和账号凭据不写进该目录。

连续播放时，应用约每 30 秒安排一次进度备份；暂停或切歌也会安排更新。恢复队列时不会自动播放，点播放后可从已备份位置继续。

卸载前点 **立即备份**，等备份完成并确认没有错误。手动备份按长度和 SHA-256 核对所需文件，即使长度没变也能发现损坏；本机原件仍在时会补写并读回校验。校验报错时先不要卸载。重装后进入同一页面，重新选择原先的文件夹（不是 `MB Data` 子目录）；Android 会要求重新授权。恢复前同样检查文件完整性，已有项目不被同 ID 的旧副本覆盖，已经设置的偏好不被旧备份覆盖。恢复的插件保持停用，请在插件详情核对权限后手动启用。没有选独立目录时，只存在 App 私有数据，卸载不会保留它。

## 外观与插件

- 手机播放页工具栏可以主动切换横屏和竖屏。全屏视频优先横屏，并隐藏系统栏；离开后把方向交还给系统。平板和分屏不强制旋转。
- 播放页的画笔菜单可直接切换封面、黑胶、磁带和三种歌词舞台，不用退出播放器改设置。对支持视频的音源，可点封面或视频按钮打开当前曲目的视频，不改变全局浏览模式。
- 播放页的 **音频输出** 打开 Android 系统设备面板，不支持时提供蓝牙设置入口。**退出电台** 只停止追加电台曲目，当前歌曲和已入队曲目继续播放。
- Android Auto 媒体入口复用手机的播放队列；选中当前曲目可从原进度继续，空队列没有续播项。语音播放只匹配当前队列内的歌名和歌手，不访问插件目录或个人页面。实际车机连接尚未验收。
- 在 **设置 → 外观** 选择本机背景图。MB 将图片降采样并另存为 PNG，删除原图不影响当前背景。连接独立数据目录后，只备份这份 PNG，不保存原图路径；重装恢复时不会覆盖已经设置的背景。可在同一处恢复默认背景。
- 在 **设置 → 插件** 检测更新或一键全部更新。只处理有 GitHub 来源的外部插件（含停用项）；安装包新增网络权限时仍需单独确认。插件更新保留原启用状态、设置和私有数据。删除插件需确认，只移除安装文件，内置音源只可停用。
- 插件网页登录不使用系统浏览器已有的登录状态。系统 WebView 不支持独立配置时，Android 9 及以上改用独立进程和一次性数据目录；没有可用的 WebView 时仍需在系统设置里启用提供程序。兼容进程只有收到返回或关闭操作才算用户取消；异常返回按启动失败处理。登录主页面的网络错误或 HTTP 5xx 会单独提示，不应据此更新 WebView；图片或嵌入框架失败不结束会话。
- 插件可在其 `signIn` 中调用 `host.oauthSignIn({authorizationEndpoint, tokenEndpoint, clientID, redirectURI, scopes})`。它打开系统浏览器，以 PKCE 和单次 `state` 换取 JSON 令牌，回跳须在服务端注册为 `com.xtreeroot.mb:/oauth2redirect`。需使用适配 Android 的客户端配置，不支持直接套用现有 YouTube 插件里的 iOS OAuth 客户端和回跳。
- 播放失败时，完整播放器会显示错误码，媒体请求返回 HTTP 状态时也会显示状态码。系统拒绝音频焦点时，迷你和完整播放器会提示；可暂停占用音频的应用，再点播放，队列和进度不变。排查时可同时试播一首已导入的本地音频，区分本地播放与平台取流，不需要提供 Cookie 或带签名的媒体地址。
- 已授权的调试设备可在复现后运行 `adb -s <设备序列号> logcat -d -s MBPlayback:I MBPluginBrowser:I '*:S'`。这两个日志标签记录播放服务连接、播放错误码、WebView 提供程序和启动阶段，不记录曲目、请求地址、账号或 Cookie。
- 插件登录结束后，可对调试包执行 `adb -s <设备序列号> shell run-as com.xtreeroot.mb cat files/plugins/data/<插件ID>/sign-in-diagnostics.json` 读取最近一次报告。仅记录插件登录脚本的已授权请求，最多 32 条：域名、路径 SHA-256、HTTP 状态码、约定的整数业务码或异常类型。不保存原始路径、查询参数、请求头、正文、Cookie 或账号信息，不进入可携带备份。
- 听歌进度到 70% 时，MB 会为自动播放的下一首先取地址和最多 256 KiB 音频，只临时放内存；下一首已有本地副本时不走网络，也不会提前播放。

## 模块

- `music`：音源与媒体、账号、资料库、互动合同。
- `bilibili`：平台端点、WBI、扫码会话、分页和响应映射。登录 Cookie 只保留在本 App 的私有音源存储中，不导入其他客户端，不随备份或设备迁移。
- `plugin`：复用 iOS 的 QuickJS 源码与宿主脚本，通过 JNI 调用。提供 ESM、私有存储、兼容现有脚本的加密接口、可取消的异步请求、媒体请求头规则和隔离的 WebView 登录。支持 ZIP、目录、GitHub 暂存与确认；插件可提供登录、主页、目录、个人集合、分类搜索、音频、视频和歌词。
- `playback`：Media3 音频服务、系统媒体会话、队列与位置恢复。只持久保存曲目身份，不保存临时流地址。
- `local`：通过系统文件选择器导入并持有音频副本，按 SHA-256 去重，读取标签、内嵌封面和歌词；不修改原文件。
- `preferences`：偏好持久化和分域代理策略；代理名单不记录账户或凭据。
- `ui`：Compose 界面、请求状态与手机/宽屏导航。视频独立解码，不替换后台音频队列。
