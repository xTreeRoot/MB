# Build 5 补充验证

打开 [图库](index.html) 或 [截图索引](SCREENSHOTS.md)。本轮共 20 张图，来自 iPhone 18 Pro / iPad Pro 13-inch (M5) 模拟器的两项相关 UI 回归：四个 Tab 的迷你播放器布局与导航、CarPlay/锁屏歌词设置开关。数据为隔离演示资料，封面占位和静音曲目不代表真实平台加载与媒体播放验收。

几何断言确认迷你播放器不与导航栏或导航按钮相交，并实际打开和收起播放页。手机浏览页保持竖屏，设备横置时也验证四个 Tab；iPad 验证横竖屏。系统正在播放的逐句歌词由独立行为回归验证，未做真实车机验收。

来源、测试名、时间与图像 SHA-256 见 [manifest.json](manifest.json)。Build 4 的完整历史截图保留在上级目录，不作为本轮全量重新验收。
