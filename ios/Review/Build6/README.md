# Build 6 播放器与封面验证

打开 [图库](index.html) 或 [截图索引](SCREENSHOTS.md)。46 张图来自 iPhone 18 Pro / iPad Pro 13-inch (M5) 模拟器的 XCTest 操作，账号、歌曲、评论和封面占位均为隔离演示资料，不能代替真实媒体或账号互动验收。

本轮修复 HTTP 封面被丢弃、播放时重复图像解码、播放器主要控制随内容滚出屏幕、队列切歌误用未来视频偏好等问题。迷你播放器直接打开队列，展开页固定进度/上下曲/歌词/评论/队列，更多菜单复用已有下载/喜欢/歌单/分享，并可打开作者其他投稿。跨曲异步来源和拖动进度会忽略旧状态；作者页面使用打开时的来源。

手机 3 项、平板 3 项相关测试通过；固定作者来源后手机交互另重跑 1 项通过。覆盖四个 Tab 不重叠、打开/收起、队列切歌、评论阅读、作者投稿、黑胶/磁带、Flow/Steps/Tilt 和平板横竖屏。截图来源、测试名、时间与 SHA-256 见 [manifest.json](manifest.json)。

[真实游客首页](real-home.png) 由正常启动的 Debug App 联网加载后，用 `simctl io screenshot` 采集，无演示参数、无登录账号。它只证明真实公开封面在手机页面显示；首页内容随平台变化。真实截图的来源与摘要见 [live-home.json](live-home.json)。另以联网探针验证首页 4 区各 6 张封面的 HTTPS 下载及 ImageIO 解码成功，真实“夜曲”搜索 17 条，原生音频解码 4096 PCM 帧。

123 项 Swift 行为/合同回归（Foundation 96、B 站 27）、公共 SwiftUI 宿主编译、手机/平板模拟器测试及通用 arm64 Release 构建通过。未签名 IPA 已通过唯一应用目录、可执行权限、Bundle 字段与 ZIP 完整性检查。114 个生产源码/工程/脚本文件的打包摘要见 [sources.sha256](sources.sha256)，路径均相对 `ios/`。
