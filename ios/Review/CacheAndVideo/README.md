# 个人资源缓存与视频状态栏（2026-11-20）

- iOS 普通视频页隐藏时间、电量等系统状态栏，返回浏览恢复；顶部安全区与视频采用同一黑色背景。
- 所有插件的个人列表、自定义个人主页及歌单、专辑、作者、播客内容按插件版本、账号、请求和分页游标缓存。内置 B 站个人资料库也使用同一缓存策略。
- 列表缓存有效期 6 小时，返回页面直接复用；下拉刷新与收藏、歌单修改后失效。过期刷新遇到网络错误时保留旧内容；取消及账号变化不会回填旧页面。
- 歌曲、歌单、专辑、作者封面、头像及锁屏封面使用统一图片磁盘缓存；图片有效期 30 天，容量上限 256 MiB，列表响应每个来源上限 32 MiB，超过容量按最近访问淘汰。已加载列表按最多四个并发预取封面。
- 图片键包含平台、完整地址和请求头摘要；请求头不写入图片索引。列表缓存不包含取流结果，播放仍解析当前媒体地址。首次加载、主动刷新、过期更新及被系统清理后仍会联网。
